# -3rd-ORDER-ACTIVE-LOW-PASS-FILTER-WITH-CUTOFF-FREQUENCY-2KHz-
This project presents the design, mathematical analysis, and LTspice simulation of a 3rd-order  active low-pass filter with a 2 kHz cutoff frequency.The filter is designed using a cascaded first-order active low-pass stage and a second-order Sallen-Key low-pass stage with TL081 operational amplifiers.

Components Used

TL081 Operational Amplifier ×2,
8.2 kΩ Metal Film Resistors ×3,
10 nF Capacitor,
20 nF Capacitor,
5 nF Capacitor,
Function Generator,
Oscilloscope (CRO/DSO) and
LTspice Simulation Software

Software Used

LTspice,
Circuit Analysis and
Mathematical Calculations

Results :

The LTspice simulation confirmed:

Maximally flat Butterworth response,
Cutoff frequency close to 2 kHz,
Approximately −3 dB gain at the cutoff frequency and
Attenuation of approximately −60 dB/decade beyond the cutoff frequency

Applications

Audio Signal Processing,
Anti-Aliasing Filters,
Biomedical Signal Conditioning,
Communication Systems and
Data Acquisition Systems.
